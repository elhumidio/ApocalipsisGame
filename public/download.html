Un solo archivo HTML. Ábrelo en cualquier navegador. No necesita instalación.

Código fuente React + Vite. Requiere Node.js.

📱 Cómo jugar en tu móvil:

1. Descarga el archivo HTML standalone

2. Ábrelo en Chrome/Safari de tu móvil

3. ¡Juega! El progreso se guarda automáticamente

Para instalar como app:

• Android: Chrome → Menú ⋮ → "Añadir a pantalla de inicio"

• iPhone: Safari → Compartir → "Añadir a pantalla de inicio"
